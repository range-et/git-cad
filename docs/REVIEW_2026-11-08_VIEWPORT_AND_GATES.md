# Review: responsive viewport loading and recurring build gates

Reviewed November 8, 2026 against HEAD `97b8143` plus the viewport/build-gate working
diff. Automated reports include its full fingerprint, including untracked files.

Acceptance: move CPU preparation off the UI thread, suppress per-object rendering,
yield during scene installation, retain supported shading/UVs, safely close/retry
loads, and make the architecture/UX/QA review cycle repeatable for future builds.

Independent reviewers: `viewport_architecture`, `viewport_ux`, `build_gate_qa`.
Reviewers worked read-only with temporary projects. The existing Love Park UI and
native application documents were not modified or restarted.

| Priority | Finding | Fix and recheck |
| --- | --- | --- |
| P1 | QA runner could report success after source files changed mid-run. | Compare starting/final HEAD, tracked diff and untracked file content; fail on drift. Independent mutation probe and durable regression pass. |
| P2 | A timed-out command could leave its descendants running. | Run checks in their own POSIX process group and kill the group on timeout/interrupt. Descendant marker probe and durable regression pass. |
| P2 | Importing CLI main alone did not validate the wheel's console entrypoint metadata. | Load the installed distribution's unique `cad-git` console entrypoint. Independent missing/broken entry probes fail as intended. |
| P2 | Diff check omitted staged edits; failed sequences did not enumerate remaining checks. | Check against HEAD, report planned/pending gates, verify failure and interruption cases. |
| P3 | Initial load text does not distinguish queued from active preparation. | Deferred; two-worker bound and object installation progress are implemented. |

Architecture found no reproducible P0/P1 in worker ownership, GUI-only renderer
access, bounded preparation, cancellation or retry. Separate probes verified that
closing a queued load skips reads and that an injected actor-upload failure can
be retried without a stale timer. Independent UX probes verified load-time mode
and edge choices, background-tab completion, stale draft detection, visible errors
and close-during-upload behavior. A temporary UI screenshot was inspected.

QA rechecked all its findings after fixes and found no remaining proven P1 in scope.
Its raw record and the UX record are retained in `docs/research/`.

## Verification evidence and limits

- Core baseline: 140 tests passed; two additional runner failure regressions pass.
- Full runner exercised CLI smoke, source/wheel builds, installed package/assets,
  geometry UI, retry/close robustness, materials UI, actual texture pixels and
  large-scene responsiveness. Final stable-tree results are generated by
  `uv run python scripts/check.py --build --ui` into ignored `build/qa/`.
- Independent 401-object / 249,800-triangle checks completed in approximately
  1.7–1.8 seconds with UI heartbeats between uploads; the largest measured gaps
  were approximately 0.34 seconds on the development Mac.
- A separate read-only 72 MB scene probe loaded 1,149 objects / 1.7 million points
  in 6.55 seconds in a 900×650 shaded viewport. See [loading notes](VIEWPORT_LOADING.md).
- Active USD/filter operations and GPU frames are not forcibly interrupted;
  there is no general out-of-core or level-of-detail renderer yet.
- Native adapters and MCP protocol behavior were unchanged, so new live-native
  and MCP protocol runs are not applicable to this patch. No new native fidelity
  claim is made. The wheel check only imports the optional MCP facade.
- Hosted GitHub Actions and branch protection were not exercised/configured;
  the checked-in workflow runs after push. Local success does not assert hosted CI.

All named reviews are scoped to this diff. The reusable process and release decision
rules live in [BUILD_GATES.md](BUILD_GATES.md), not in a universal certification.
